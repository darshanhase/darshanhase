## Featured Projects

### [TradeLens AI](https://github.com/darshanhase/tradelens-ai) &nbsp;·&nbsp; [Live Demo](https://darshanhase.github.io/tradelens-ai/)
Spreadsheet-first personal trading journal — paste rows straight from Excel, import CSV, and get computed metrics (profit factor, drawdown, breakdowns) plus rule-based psychology insights. React + TypeScript + IndexedDB, works fully offline, no backend required. 62 passing tests.

### [Ledger — Telegram Expense Bot](https://github.com/darshanhase/expense_bot)
Log expenses by text in plain language (`swiggy 420 dinner`, `1.5k myntra shirt`) — parses amounts and categories, stores them in SQLite, and regenerates an offline HTML dashboard. No server, no cloud; everything stays on your machine.

### [API Probe](https://github.com/darshanhase/api-probe)
REST API testing and monitoring tool built with Spring Boot. Tracks endpoint health, response times, and failure patterns across services.

### [Website Health Monitor](https://github.com/darshanhase/website-health-monitor)
Flask-based availability tracking system that monitors uptime and alerts on downtime events across multiple web targets.

### [Algo Visualizer](https://github.com/darshanhase/Algo-Visualizer)
Interactive algorithm visualizer — animated Bubble, Merge, Quick, Heap Sort and Linear/Binary Search with speed control and a clean UI.
